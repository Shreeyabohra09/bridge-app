# Bridge

An AI social coach for neurodivergent young adults, built by Team Ctrl Alt Elite with First Place AZ for the North American AI Challenge for Neurodiverse Learning (Scottsdale Launchpad, 2026).

This repo holds the Bridge prototype designed in Figma Make, packaged as a Vite + React app so it can be hosted on Vercel.

## Run locally

```
npm install
npm run dev
```

## Deploy

Import this repo in Vercel. It detects Vite automatically (build: `npm run build`, output: `dist`).
